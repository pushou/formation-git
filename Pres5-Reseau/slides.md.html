Mettre à jour main depuis « origin » (fetch + rebase/merge). 2. Créer une branche locale « feature » à partir de main. 3. Pousser « feature » sur « origin » (push -u). 4. Ouvrir une Pull/Merge Request depuis « feature » vers « main ». 5. Après merge, supprimer la branche « feature » (origin puis local). --- Diagramme : ******************************************************************************* * Internet * * +-----------------------------+ +-----------------------------+ * * | Dépôt local | | Dépôt officiel (origin) | * * | branches: main, feature | | branche: main | * * +---------------+-------------+ +---------------+-------------+ * * | 1. fetch/rebase main ^ * * |---------------------------------------| * * | | * * | 2. git checkout -b feature | * * | | * * | 3. git push -u origin feature --------> push * * | | * * '---- 4. ouvrir PR vers main -----------> PR * * [review/merge] * * <----------- 5. sync local main --------- merge * ******************************************************************************* --- ## Dépôt public - **Contributions extérieures via des forks.** - Le dépôt officiel est *lisible* par tous. - Chacun peut créer une *copie privée* (fork). - Ensuite, *on soumet* des changements depuis son fork (PR/MR). - **Contributions internes : deux options** - Via forks : procédures homogènes, moindre privilège. - Via accès direct en écriture : un peu plus ergonomique. --- ## Utilisation d'un fork (upstream/origin) Étapes : 1. Configurer « upstream » (officiel) et « origin » (fork personnel). 2. Récupérer les mises à jour d'upstream (fetch + rebase/merge). 3. Travailler en branche locale, puis push vers « origin ». 4. Ouvrir une PR/MR de « origin:feature » vers « upstream:main ». --- Diagramme : ******************************************************************************** * * * +--------------------+ Internet +--------------------+ * * | Dépôt officiel | <------------------> | Fork personnel | * * | "upstream" | | "origin" | * * +----------+---------+ +----------+---------+ * * ^ ^ * * | 1. add remote upstream | * * | 2. fetch upstream | 3. push * * | | * * +---------------+------------+ | * * | Dépôt local |------------------------------+' * * | branches: main, feature | * * +----------------------------+ * * | * * '---- 4. PR: origin/feature -> upstream/main * * * ******************************************************************************** --- ## Forge sociale - **Application web qui facilite :** - *Visualisation* du dépôt (fichiers, versions, branches…) - Création et mise à jour de *forks* - *Soumission* de changements (pull/merge requests) - *Discussion/revue* des changements avant acceptation - Et plus encore… - **Pour ce TP : GitHub ou GitLab IN2P3** --- ## Démo : Forges sociales --- ## TP : Réseau et forges
