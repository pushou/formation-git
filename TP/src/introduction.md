# Introduction

Bienvenue dans les supports de cette formation git. Vous trouverez à gauche de
cette page un sommaire des différents énoncés de TP. Chaque énoncé de TP
commence par un lien vers la présentation théorique correspondante.

Il est également possible d’aller d’une page à l’autre dans l’ordre du sommaire
avec les boutons flèches en bas de page ou les flèches gauche et droite de votre
clavier.
