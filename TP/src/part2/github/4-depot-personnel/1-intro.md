# Dépôt personnel

Maintenant que vous savez contribuer à un dépôt GitHub existant, il est temps de
passer derrière les fourneaux et de devenir chef cuisinier en créant votre
propre livre de cuisine sur GitHub.

Dans ce chapitre, vous allez d'abord apprendre à [créer et configurer un
dépôt](2-creation-depot.md) pour y centraliser vos recettes de cuisine. Vous
découvrirez ensuite les bases de l'[intégration
continue](3-integration-continue.md), qui permet d'automatiser des procédures de
contrôle qualité sur votre dépôt.
