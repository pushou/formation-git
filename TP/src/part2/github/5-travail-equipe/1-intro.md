# Travail en équipe

La dernière étape du parcours consiste à travailler en brigade ! Dans ce
chapitre, vous recommencerez à travailler en collaboration, mais cette fois ce
sera au sein d’un dépôt GitHub géré par l'un d'entre vous.

Pour plus de réalisme, nous allons simuler un scénario courant dans le monde de
l'_open source_, à savoir la [transformation d'un projet personnel en projet
collectif](2-projet-commun.md) par ouverture de celui-ci aux contributions
extérieurs. Nous verrons que sur le plan technique l’opération est assez simple,
mais que sur le plan humain il y a aussi du travail si on veut une bonne
dynamique de groupe.

Vous irez ensuite plus loin dans l’automatisation grâce à une intégration
continue plus avancée, capable de déployer automatiquement votre livre de
cuisine sous forme de site web statique. Cette pratique s'appelle le
[déploiement continu](3-deploiement-continu.md).

L’objectif est de passer d’un travail individuel à une dynamique de production
collective, où chaque membre contribue à un projet commun et robuste.
