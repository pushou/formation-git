# Dépôt fermé sur GitLab

Dans cette variante, nous travaillerons sur un groupe GitLab fermé, qui
n'est accessible qu'à l'équipe projet. Dans un premier temps, chacun pourra expérimenter la création de dépôt, puis nous passerons vers une édition collaborative d'un même dépôt. À cette occasion, nous verrons comment valider les contributions de chacun via le mécanisme des _merge
requests_, qui permet d'ajouter un niveau de vérification supplémentaire par rapport à un simple _merge_.
